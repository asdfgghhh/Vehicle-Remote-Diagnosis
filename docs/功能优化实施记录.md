## 七、部署说明

> **修订**：当前部署以根目录 `deploy.sh [tag] [registry]`（本地构建并推送镜像）+ 服务器 `docker compose pull` / `docker compose up -d --remove-orphans` 为准，基础设施（MySQL/Redis/Kafka/EMQX/Nacos/ClickHouse）部署于服务器宿主机。以下为历史方案说明。

### 7.1 启动 Python DBC 解析服务（历史方案，已废弃）
```bash
cd dbc-parser-service
pip install -r requirements.txt
python app.py
# 或 Docker: docker build -t vrd-dbc-parser . && docker run -d -p 8090:8090 vrd-dbc-parser
```
> ⚠️ 当前 service-dbc 使用纯 Java 原生解析器，无需启动 Python 服务。

### 7.2 执行新增 SQL
```bash
# 在 MySQL 中执行
mysql> source sql/mysql/07_vrd_diagnosis.sql
mysql> source sql/mysql/08_alert_rule.sql
```
> 注：SQL 实际位于 `backend/sql/mysql/` 目录（01-08），完整初始化按编号顺序执行。

### 7.3 前端启动
```bash
cd frontend
npm install
npm run dev
```

### 7.4 Nacos 配置
将 `nacos-configs/service-diagnosis.yml` 导入 Nacos 配置中心。
